# 메모리 — 모바일 Claude Code 작업 환경 정리

향후 참고용 메모. 작업 환경의 구조와 왜 이렇게 동작하는지 기록.

## 아키텍처 한눈에 보기

```
[사용자 핸드폰]                  [Anthropic 클라우드]              [Google Drive]
  Claude Code 앱   ─명령─►   Linux 컨테이너                  ─업로드─►   모바일코드/
  (UI/화면)        ◄─결과─    /home/user/모바일작업/...                  모바일작업/
                              (실제 작업 공간)                            모바일코드연습/
                                                                            └─ 파일들
```

핸드폰은 **화면/입력 장치**일 뿐. 실제 작업은 클라우드 컨테이너에서 일어남.

## 핵심 사실

### 1. Claude Code 세션이 동작하는 위치
- **클라우드 Linux 컨테이너** (Anthropic이 제공)
- 핸드폰 내장 저장소 아님
- 세션 종료/유휴 시 컨테이너 회수 → 모든 로컬 파일 소실

### 2. 영구 보관 수단
- **Git 저장소** (코드 프로젝트): 자동으로 GitHub에서 clone/push
- **Google Drive** (비-git 파일): 사용자가 "올려줘" 할 때 업로드
- 컨테이너 로컬: 임시, 세션 단위

### 3. 속도 비교 (왜 클라우드→Drive가 빠른가)

| 경로 | 속도 | 특징 |
|------|------|------|
| 클라우드 컨테이너 → Drive | ⚡ Gbps급 | 데이터센터 내부 통신 |
| 핸드폰 → Drive | 🐌 모바일망 속도 | WiFi/LTE 업로드 한계 |
| 핸드폰 → 클라우드 → Drive | 동일 | 핸드폰은 명령만 보내므로 영향 없음 |

→ Claude에게 작업 시키면 **클라우드에서 처리되므로 핸드폰 업로드 속도와 무관**

### 4. 핸드폰 내장 저장소 작업이 비효율인 이유
- Claude가 핸드폰 파일시스템에 접근 불가
- 모바일 IDE(Termux 등)로 본인이 직접 작성해야 함
- 핸드폰 CPU가 클라우드 컨테이너보다 느림
- 결국 Drive 업로드는 모바일 네트워크로 해야 함
- → 모든 면에서 손해

## 표준 작업 흐름

```
1. 핸드폰에서 Claude Code 앱으로 명령 입력
   예: "○○ 만들어줘"

2. Claude가 클라우드 컨테이너 로컬에 파일 작성
   /home/user/모바일작업/모바일코드연습/○○

3. (작업 마무리 시) 사용자가 "올려줘" 입력

4. Claude가 MCP로 Drive에 업로드
   → 모바일코드/모바일작업/모바일코드연습/○○

5. 핸드폰 Drive 앱에서 자동 동기화로 확인 가능
   (또는 PC Drive에서 확인)
```

## 자주 쓰는 명령어 패턴

| 사용자 입력 | Claude 동작 |
|------------|------------|
| "○○ 만들어줘" | 로컬 파일 작성 |
| "올려줘" | 직전 파일 Drive 업로드 |
| "변경된 거 다 올려줘" | 디렉토리 전체 업로드 |
| "Drive에서 ○○ 가져와줘" | Drive → 로컬 다운로드 |
| "이번 세션 거 묶어서 올려줘" | tar.gz 등으로 묶어 업로드 |

## 다음 세션 시작할 때

새 컨테이너에서 작업 이어가려면:

```
1. 새 세션에서 Claude에게:
   "Drive 모바일코드/모바일작업/모바일코드연습 폴더에서 
    이전 작업 파일들 가져와줘"

2. Claude가 MCP로:
   - search_files로 폴더 검색
   - 각 파일을 download_file_content로 가져와서
   - /home/user/모바일작업/모바일코드연습/에 복원

3. 이전 상태에서 이어서 작업
```

## 보안/주의

- Drive에 올리는 파일에 비밀번호/API 키 포함되지 않았는지 확인
- 공유 설정 변경 시 의도치 않은 공개 주의
- 세션 공유 링크는 읽기 전용이지만 내용 노출됨
