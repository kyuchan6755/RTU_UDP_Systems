# Claude Code 모바일 앱 - 우측 상단 메뉴 사용설명서

세션 화면 우측 상단의 점 3개(⋮) 아이콘을 누르면 나타나는 메뉴 5가지의 기능 설명입니다.

---

## 메뉴 구성

| 순서 | 메뉴명 | 아이콘 | 기능 요약 |
|------|--------|--------|-----------|
| 1 | 브랜치 복사 | 복사(겹친 사각형) | 현재 작업 중인 git 브랜치명을 클립보드에 복사 |
| 2 | 모델 변경 | 화살표 교차 | 세션에서 사용하는 Claude 모델 변경 |
| 3 | 공유 | 공유 아이콘 | 세션 링크를 다른 사람/앱에 공유 |
| 4 | 이름 변경 | 연필 | 세션 제목 변경 |
| 5 | 보관 | 휴지통 | 세션을 보관함으로 이동 (목록에서 숨김) |

---

## 1. 브랜치 복사

현재 세션이 작업 중인 git 브랜치명을 **클립보드에 복사**합니다.

- 표시 예: `claude/mount-mobile-code-d...` (생략 표시)
- 실제 복사되는 값: 전체 브랜치명 (예: `claude/mount-mobile-code-drive-ma8ZT`)
- **사용 시점**
  - PC에서 동일 브랜치를 체크아웃할 때: `git fetch && git checkout <붙여넣기>`
  - PR 링크 생성 시 브랜치명이 필요할 때
  - 다른 세션/도구에 브랜치 정보 전달할 때

---

## 2. 모델 변경

이 세션에서 다음 메시지부터 사용할 Claude 모델을 변경합니다.

- 선택 가능 모델 예시
  - **Opus 4.7** (claude-opus-4-7) - 가장 강력, 1M 컨텍스트, 비용 높음
  - **Sonnet 4.6** (claude-sonnet-4-6) - 균형형
  - **Haiku 4.5** (claude-haiku-4-5) - 빠르고 저렴
- **선택 기준**
  - 복잡한 리팩터링/설계: Opus
  - 일반 코드 수정: Sonnet
  - 단순 질의/요약: Haiku
- 변경 후 다음 응답부터 적용 (이전 응답은 그대로)

---

## 3. 공유

현재 세션의 **링크를 외부에 공유**합니다.

- Android 공유 시트가 열려 카카오톡/메시지/메일/링크복사 등 선택 가능
- 공유받은 사람은 세션 내용을 **읽기 전용**으로 확인 가능
- **주의**
  - 세션 내용에 민감 정보(비밀번호, API 키, 내부 코드)가 있는지 확인 후 공유
  - 한 번 공유한 링크는 회수가 어려울 수 있음

---

## 4. 이름 변경

세션 목록에 표시되는 **세션 제목을 수정**합니다.

- 기본값: 첫 메시지 기반 자동 생성 (예: `Mount mobile code directory to Goo...`)
- 변경 권장 케이스
  - 작업 내용을 명확히 구분하고 싶을 때 (예: `RTU H03 control 버그수정`)
  - 자동 생성된 이름이 영문/생략으로 알아보기 어려울 때
- 세션 내용/대화는 그대로 유지되며 이름만 변경됨

---

## 5. 보관 (Archive)

세션을 **보관함으로 이동**하여 메인 세션 목록에서 숨깁니다.

- 휴지통 아이콘이지만 **삭제가 아닌 아카이브** 처리
- 보관된 세션은 보관함 메뉴에서 다시 꺼낼 수 있음
- **사용 시점**
  - 완료된 작업 세션을 정리할 때
  - 메인 목록이 너무 많아 가독성이 떨어질 때
- 보관해도 GitHub에 push된 코드/PR은 그대로 유지됨

---

## 빠른 사용 팁

- **PC로 작업 이어가기**: `브랜치 복사` → PC에서 `git checkout <붙여넣기>`
- **비용 절약**: 간단한 질의는 `모델 변경`으로 Haiku 사용
- **팀 공유**: `공유`로 세션 링크 전달 (민감 정보 확인 후)
- **세션 정리**: 완료된 작업은 `보관`으로 깔끔하게 관리
- **검색 편의**: `이름 변경`으로 의미 있는 제목 부여
